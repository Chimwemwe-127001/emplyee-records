# Employee Record Management System

A full-stack web application for managing employee records with authentication.

## Features

- **Authentication**: Sign up, sign in, and sign out functionality using NextAuth.js
- **CRUD Operations**: Create, read, update, and delete employee records
- **MongoDB Integration**: Data persistence using MongoDB and Mongoose
- **Responsive Design**: Mobile-friendly UI built with Tailwind CSS
- **Form Validation**: Client and server-side validation for all forms
- **Error Handling**: Proper error handling and user feedback

## Tech Stack

- **Frontend**: Next.js, React, Tailwind CSS
- **Backend**: Next.js API Routes
- **Database**: MongoDB with Mongoose
- **Authentication**: NextAuth.js with JWT
- **State Management**: React Hooks
- **Form Handling**: React Hooks
- **Styling**: Tailwind CSS
- **Notifications**: React Hot Toast
